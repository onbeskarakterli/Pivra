# Pivra v0.2.9-dev development features

These changes are on `dev`. The published stable release remains v0.2.8
and the previously verified AUR package is `0.2.8-1`. Physical acceptance
of this development batch is pending. See the [progress and recovery log](V0.2.9_PROGRESS.md).

## Viewer and file actions

| Action | Behavior |
| --- | --- |
| Ctrl+Shift+C or Compare Images… | Choose a second still photo and compare it with the active photo. Escape returns to the preserved viewer. |
| Compare Selected Images | Compare exactly two eligible marked thumbnails in their visible order. |
| Ctrl+click, Shift+click, Ctrl+Shift+click | Toggle a mark, select a range, or add a range. The photograph or video in the main viewer keeps its own identity. |
| Ctrl+A with thumbnail focus | Mark every item in the current thumbnail filter. Escape first clears thumbnail marks. |
| F2 or Delete with multiple visible marks | Preview a batch rename or confirm moving the indicated count to system Trash. With fewer than two marks, these keys act on the current viewer item. |
| Transfer menu | Copy To or Move To selects a local destination and asks whether to skip collisions or keep both names. |
| Ctrl+C or Clipboard → Copy File(s) | Copy the current filtered marks, or the active file when there are no marks, as desktop file clipboard content. |
| Clipboard → Copy File Path / Copy Image | Copy the active absolute path or the existing still photo pixels. GTK text editing retains its own Ctrl+C. |
| Ctrl+Z | Undo the latest reversible operation in this window. GTK text editing retains its own Ctrl+Z. |
| S or Save Video Frame… | Capture the current displayed video frame before the save dialog. PNG is the default. Use `.jpg` or `.jpeg` for JPEG. |
| Sort By | Use name, modified date, size or file type, ascending or descending. Natural ascending is the default. |

Comparison provides per-pane Fit, Fill and 100%, wheel zoom, drag pan, reset and
swap. Link views starts enabled and transfers relative zoom and normalized
center between different resolutions. It supports one comparison or decode at
a time across the process, with a 64 MiB estimated texture budget per pane.
The secure still-image pipeline is reused. GIF, APNG, known animated images
and DNG are excluded from comparison. [Comparison controller](../../src/window/compare_view.rs)

The thumbnail strip stores marks by path and computes batch scope from the
current filter and order. Marks use a paint-only outline, independent of the
active item highlight and thumbnail work scheduling. Sorting reuses metadata
from the existing folder worker and preserves the active path, filter and
marks. It drives both navigation and slideshow order. Unknown metadata sorts
last. The preference uses the existing view-mode settings. Older stable builds
can fall back to Fit when the dev configuration includes a sort line.
[Thumbnail selection](../../src/thumbnail_strip/selection.rs) · [Media sorting](../../src/media_sort.rs)

File actions validate pinned identities and use no-clobber publication. A
batch admits at most 128 files. The window-local history retains up to 32
operations and reserves at most 192 file receipts. A grouped inverse retains
unresolved receipts and releases completed ones. Copy and frame export stay
outside the history. Cross-filesystem Move verifies the staged bytes before
retiring the source. Cross-filesystem undo may restore the bytes with a new
inode, which makes an older receipt for the previous inode refuse safely.
Transfers accept regular local files. Batch rename stages chains and cycles.
A genuine rollback collision preserves the staged file and reports its
recovery path. [Undo](../../src/undo.rs) · [Transfer](../../src/window/batch_operations/transfer.rs) · [Rename](../../src/rename/batch.rs)

Clipboard file formats include `text/uri-list` and the Nautilus copy format.
Clipboard contents are owned by the desktop protocol and can disappear when
Pivra exits. Video frame export supports stock GTK/GStreamer and the Pivra
OpenGL adapter while the ordinary video is visible. It reads pixels only on
explicit capture. Playback-rate controls require the Pivra OpenGL adapter and
the supported audio pipeline. Stock GTK, including subtitle-induced fallback,
retains ordinary playback. [Clipboard](../../src/window/clipboard.rs) · [Video frame export](../../src/video_frame_export.rs)

## Validation

Formatting, locked compilation and whitespace checks passed. Focused Rust
tests covered normalized comparison transforms, filtered selection, transfer
safety and group retry, all rename modes and cycles, sort keys, clipboard
payloads and history file limits. Cross-device Move and its inverse ran across
two Linux mounts with actual staged copies.

Controlled GTK/X11 checks covered comparison, thumbnail selection, bulk Trash
with isolated real GVfs, batch rename, sorting, clipboard, menus and mixed
Undo. They also verified frame export on stock GTK and the llvmpipe OpenGL
test path, and that comparison prevents capture of a hidden video. The mixed
Undo probe used one real production window, a native folder chooser and four
consecutive inverse actions. These results support development validation.
Physical GNOME, GPU, desktop clipboard and portal behavior are pending.
[Per-task evidence and commit references](V0.2.9_PROGRESS.md)

## Combined native GNOME acceptance

Use a disposable local directory with copies of assorted photos and videos.
Make a second disposable directory for transfer checks. Keep valuable originals
outside these directories.

```sh
cd ~/Pivra
git switch dev
git pull --ff-only origin dev
cargo run --locked --
```

- **A. Video.** Test normal hardware playback and the rate menu. Export playing
  and paused frames with S and the video menu. Open the PNG and JPEG, check
  orientation, color, size, timestamp and playback continuity. Cancel a save and
  decline an overwrite. Confirm a subtitle-routed stock video plays at its
  supported rate.
- **B. Undo and notifications.** Rename a file and move another to Trash. Wait
  for a toast to disappear, change folders in the same window, then use Ctrl+Z.
  Verify recent toasts address the correct operation and a focused text entry
  still uses native Undo.
- **C. Comparison.** Open a large portrait and a landscape side by side. Check
  linked and unlinked zoom/pan, display modes, swap and reset. Resize, toggle
  fullscreen and press Escape. Confirm the original viewer state returns.
- **D. Thumbnail selection.** Verify ordinary click, Ctrl and Shift ranges,
  Ctrl+A inside the strip, Escape and mark counts when switching filters.
  Remove one disposable marked file externally and check reconciliation.
- **E. Batch Trash.** Confirm the count on a mixed-media group and restore it
  with one Ctrl+Z. Create a disposable filename collision before Undo. Clear the
  collision and retry to verify only the failed file is restored again.
- **F. Copy and Move.** Pick the second directory, try Unicode names and both
  collision choices, and cancel one transfer. Verify grouped Move undo. A copy
  remains a copy when Ctrl+Z is used.
- **G. Batch Rename.** Preview all four modes on copied files with mixed
  extensions. Check duplicate detection and cancel. Apply a rename and verify
  one Ctrl+Z restores the group.
- **H. Sorting.** Try all key and direction choices, retain selection and
  marks, check slideshow order and reopen Pivra to verify persistence.
- **I. Clipboard.** Paste file paths as text, files into Nautilus, and photo
  pixels into a suitable application. Verify Ctrl+C in an editable control.
- **J. Menu and ordinary viewer.** Use cascading Transfer, Clipboard and Sort
  By near screen edges. Check keyboard dismissal, focus and normal photo,
  slideshow, thumbnail, and navigation behavior.
